## 1. 현재 구현 상태

**Node 서버 하나로 회원가입·로그인, 학업 대시보드, 과목 관리, 성적 분석 화면을 실행할 수 있다.** 계정과 세션은 SQLite에, 사용자가 입력한 과목은 브라우저의 `localStorage`에 저장한다. 학과·학사 기준·초기 과목은 예시 데이터다.

| 기능 | 현재 구현 내용 |
| --- | --- |
| 회원가입·로그인 | 이름·이메일·비밀번호로 가입, 가입 후 자동 로그인, 기존 계정 로그인, 사용자 이름 표시 |
| 세션·로그아웃 | 쿠키와 SQLite 기반 세션, 최대 24시간 유지, 서버 재시작 후 유효 세션 유지, 로그아웃 시 세션 폐기 |
| 학업 현황 | 누적 GPA, 취득 학점, 현재 수강 학점, 선택 학년의 수료 기준까지 남은 학점 표시 |
| 현재 학년 선택 | 1~4학년 선택 시 잔여 학점 재계산. 선택값은 이 브라우저에서 로그인 사용자 ID별로 저장 |
| 과목 관리 | 과목 추가·수정·삭제, 삭제 확인 창, 학기별 목록 조회, 과목 개수 표시 |
| 성적 입력 | 전공·부전공·교양, 이수 완료·수강 중, 성적 및 재수강 여부 입력. 수강 중 과목은 성적 없이 저장 |
| 과목 저장 | 새로고침 후 유지. 저장 이력이 없으면 예시 과목 표시, 전체 삭제 후에는 빈 목록 유지. 저장 실패 시 오류 표시 |
| 성적 분석 | 별도 화면에서 누적 GPA, 선택 학기 GPA, 분석 학기 수, 전체·전공·교양별 학기 GPA 그래프 제공 |
| 상대평가 시뮬레이션 | 수강자 수와 A+~D0 등급별 비율 변경 시 예상 인원을 막대그래프와 표로 표시 |
| 화면·API 제공 | 필요한 HTML·CSS·ES 모듈·예시 JSON을 같은 서버에서 제공. 서버 소스·DB·설정 파일은 정적 공개 대상에서 제외 |

## 2. 실행 방법

### 준비 사항

- Node.js **24.12.0 이상**과 웹 브라우저가 필요하다.
- 외부 npm 패키지 의존성이 없어 별도 `npm install`이 필요하지 않다.
- Node 내장 HTTP 서버와 SQLite를 사용하므로 별도 DB 서버를 설치하지 않는다.
- 아래 명령은 Windows PowerShell 기준이다. `npm.cmd`를 사용하면 `npm.ps1` 실행 정책 문제를 피할 수 있다.

### 기본 실행

```powershell
Set-Location -LiteralPath 'D:\programming_folder\2026 ENDPoinT'
node --version
npm.cmd start
```

브라우저에서 [http://localhost:3000/](http://localhost:3000/)에 접속한다.

1. 미로그인 상태에서는 로그인 화면으로 이동한다.
2. 회원가입 또는 로그인에 성공하면 학업 대시보드로 이동한다. 회원가입 이름은 공백 제거 후 1~50자, 비밀번호는 15~128자다.
3. 대시보드에서 학년을 선택하고 과목을 추가·수정·삭제하거나 조회 학기를 변경한다. 과목 변경 시 학업 요약도 갱신된다.
4. **성적 분석 및 관리**를 누르면 성적 분석 화면으로 이동한다. 학기 GPA를 조회하고 그래프의 성적 구분이나 상대평가 인원·비율을 변경한다.
5. 과목 변경 후 성적 분석 화면을 다시 열거나 새로고침하면 저장된 과목을 반영한다.
6. 로그아웃 버튼으로 세션을 종료한다. 서버 종료는 실행 터미널에서 `Ctrl+C`를 누른다.

| 주소 | 용도 |
| --- | --- |
| `/` | 로그인 여부에 따라 로그인 화면 또는 학업 대시보드로 이동 |
| `/login.html` | 로그인·회원가입. 로그인 중이면 대시보드로 이동 |
| `/index.html` | 학업 대시보드·과목 관리 |
| `/grade-analysis.html` | 성적 분석·상대평가 예상 인원 |

HTML 파일을 직접 열거나 Live Server로 실행하면 인증 API가 연결되지 않는다. 반드시 위 Node 서버의 HTTP 주소로 접속한다. URL에 `public` 폴더명을 붙이지 않는다. 대시보드와 분석 화면은 로딩 시 인증 API로 로그인 상태를 확인하고, 미로그인 사용자를 로그인 화면으로 이동시킨다.

### 개발 모드와 테스트

```powershell
# 서버 코드 변경 시 자동 재시작
npm.cmd run dev
```

화면 파일을 수정한 뒤에는 브라우저를 새로고침한다. 별도 터미널에서 테스트를 실행할 수 있다.

```powershell
npm.cmd test
```

## 3. 환경 설정

기본 실행에는 `.env` 파일이 필요하지 않다. 설정을 바꾸려면 `.env.example`을 참고해 프로젝트 루트에 `.env`를 작성한다. 이미 `.env`가 있으면 필요한 항목만 수정한다.

| 변수 | 기본값 | 의미 |
| --- | --- | --- |
| `PORT` | `3000` | 서버 포트 |
| `HOST` | `127.0.0.1` | 서버 바인딩 주소. 기본값은 로컬 접속용 |
| `APP_ORIGIN` | `http://localhost:3000` | 인증 POST 요청을 허용할 브라우저 출처 |
| `NODE_ENV` | 예시 설정: `development` | `production`일 때 HTTPS 출처 검사와 Secure 쿠키 적용 |
| `DB_PATH` | `storage/team07.db` | 계정·세션·인증 요청 제한 기록을 저장할 SQLite 경로 |

포트를 바꾸려면 포트와 출처를 함께 설정한다.

```powershell
$env:PORT = '3001'
$env:APP_ORIGIN = 'http://localhost:3001'
npm.cmd start
```

이 경우 [http://localhost:3001/](http://localhost:3001/)로 접속한다. 위 환경변수는 현재 PowerShell 세션에 유지된다. 기본값으로 돌아가려면 새 터미널에서 실행하거나 설정을 다시 변경한다.

`APP_ORIGIN`의 프로토콜·호스트·포트는 브라우저 주소와 일치해야 한다. 예를 들어 `localhost`와 `127.0.0.1`은 서로 다른 출처다. 다른 기기에서 접근하려면 `HOST`와 `APP_ORIGIN`도 그 접속 주소에 맞춰야 한다. 운영 모드는 HTTPS 역방향 프록시와 `APP_ORIGIN=https://실제도메인` 구성이 필요하다.

## 4. 데이터 저장과 계산 규칙

### 저장 위치

| 데이터 | 저장 위치 및 범위 |
| --- | --- |
| 계정·비밀번호 해시·세션·인증 시도 기록 | 서버의 `storage/team07.db`. 파일이 없으면 실행 시 생성하고, 기존 파일은 재사용 |
| 사용자 입력 과목 | 해당 브라우저·출처의 `localStorage`, 키: `team07.courses`. **로그인 계정별로 분리되지 않음** |
| 선택 학년 | 같은 브라우저의 `localStorage`, 키: `endpoint:academic-year:<사용자 ID>` |
| 초기 예시 과목 | `data/courses.json`의 6개 과목. 저장된 과목이 없을 때 사용 |
| 학과·기본 학년 | `data/user_info.json`의 예시 정보. 화면 이름은 실제 로그인 계정에서 조회 |
| 수료·졸업 기준 | `data/academic_requirements.json`의 예시 기준 |
| 상대평가 초기값 | `data/grading_policy.json`의 수강자 수 40명과 개별 등급 비율 |

과목 목록은 같은 브라우저에서 다른 계정으로 로그인해도 공유된다. 로그아웃해도 과목은 남으며, 다른 브라우저·기기·포트에서는 별도 저장소를 사용한다. 브라우저 사이트 데이터를 삭제하면 과목과 학년 선택값이 사라진다. 서버 DB에는 과목을 저장하지 않는다.

예시 과목은 최초 화면 표시만으로 저장소에 덮어쓰지 않는다. 과목을 추가·수정·삭제하면 당시 전체 목록을 저장한다. 모든 과목을 삭제해 저장된 빈 배열은 새로고침 후에도 유지된다.

### 계산 기준

- GPA는 4.5 만점이며, 이수 완료 과목의 `학점 × 평점` 합계를 해당 과목의 학점 합계로 나눈다. F는 0점으로 GPA에 포함하며 수강 중 과목은 제외한다. 계산 대상이 없으면 화면에 `--`를 표시한다.
- 취득 학점은 이수 완료 과목 중 F가 아닌 과목의 학점을 합산한다. 수강 학점은 수강 중 과목만 합산한다.
- 수료 기준 잔여 학점은 `max(선택 학년의 누적 수료 기준 - 취득 학점, 0)`이다. 예시 기준은 1학년 33, 2학년 65, 3학년 98, 4학년 130학점이다.
- 재수강 여부는 기록하지만 이전 성적 대체나 중복 학점 제거는 하지 않는다. 입력된 완료 과목을 모두 계산한다.
- 학기 그래프는 `YYYY-1` 또는 `YYYY-2` 형태의 학기를 사용하며, 이수 완료 과목의 학점 가중 평균을 표시한다.
- 상대평가 비율은 `15 = 15%` 형태의 **각 등급별 비율**이다. 합계가 100%보다 작으면 나머지는 `기타`로 분류하고, 100%를 초과하면 오류를 표시한다. 소수 인원은 최대 나머지 방식으로 배분해 전체 인원 합계를 맞춘다.
- 상대평가 인원·비율 입력값은 현재 화면의 계산에 사용하며 저장하지 않는다. 절대평가 인원 예측은 지원하지 않는다.

예시 과목과 기본 1학년 설정으로 처음 접속했을 때의 값은 다음과 같다. 저장된 과목·학년이 있으면 달라질 수 있다.

| 항목 | 예시 결과 |
| --- | --- |
| 누적 GPA | 3.00 |
| 취득 학점 | 12학점 |
| 현재 수강 학점 | 2학점 |
| 1학년 수료까지 남은 학점 | 21학점 |
| 2026-1 GPA | 4.00 |
| 2026-2 GPA | 1.50 |

## 6. 인증 API

| 메서드 | 경로 | 요청·응답 |
| --- | --- | --- |
| `POST` | `/api/auth/signup` | `{ name, email, password }` → `{ user }`, 자동 로그인 |
| `POST` | `/api/auth/login` | `{ email, password }` → `{ user }` |
| `GET` | `/api/auth/me` | `{ user: { id, email, name } }`, 미로그인 시 401 |
| `POST` | `/api/auth/logout` | `{}` → `{ message }` |

POST 요청은 JSON과 허용된 Origin을 요구한다. 브라우저의 같은 출처 요청은 인증 쿠키를 함께 사용한다. 오류 응답 형식은 `{ message }`다. 현재 학사 데이터 저장·조회용 개인 API는 없다.

비밀번호는 salt를 적용한 scrypt 해시로 저장한다. 세션 토큰은 DB에 SHA-256 해시로 저장하며 쿠키에는 HttpOnly·SameSite 설정을 적용한다. 인증 시도는 IP당 합산 15분에 30회, 로그인은 이메일별 15분에 10회로 제한한다. 설정의 자세한 내용은 `README-auth.md`를 참고한다.

- 대시보드·성적 분석 HTML, CSS·JS와 재귀 import, 예시 JSON 제공, 로그인 상태에 따른 기본 주소 이동, 비공개 파일 차단을 HTTP로 확인한다.
- 과목 추가·수정·삭제·필터·저장·빈 목록 유지·저장 실패 처리에 대한 테스트가 포함된다.

일부 학점·GPA 테스트 파일은 예시 계산값을 출력하는 형태로, 엄격한 단언 검증이 충분하지 않다. 그래프 전용 테스트 파일도 없다. **이번 문서 갱신에서는 브라우저 화면 조작과 시각적 검증을 새로 수행하지 않았다.** 학년 선택과 학기 필터 등 화면 기능 설명은 현재 소스 확인에 근거한다. Node 내장 SQLite의 ExperimentalWarning이 출력됐지만 테스트는 정상 종료됐다.

## 8. 남은 구현과 제한

- 과목의 계정별 서버 저장, 다른 기기 간 동기화, 내보내기·가져오기.
- 실제 학교 학적·포털 연동 및 공식 학과·입학 연도별 학사 기준 적용.
- 총학점·전공·교양·부전공·복수전공 등을 종합한 졸업요건 판정. 현재 화면은 학년별 수료 잔여 학점만 계산한다.
- 학교별 재수강 대체·중복 인정·P/F 등 계산 정책 적용. 현재 성적 입력은 A+~D0 및 F를 지원한다.
- 부전공 단독 그래프 필터. 과목 입력과 전체 그래프에는 포함되지만 별도 선택지는 없다.
- 이메일 소유권 확인, 비밀번호 재설정.
- 화면 동작·그래프 및 학점 계산에 대한 자동 검증 보강.

## 9. 실행 문제 해결

| 증상 | 확인 방법 |
| --- | --- |
| `node` 또는 `npm`을 찾을 수 없음 | Node.js 설치·PATH를 확인하고 터미널을 새로 연다. `node --version`으로 버전을 확인한다. |
| PowerShell에서 `npm.ps1` 실행 정책 오류 | `npm.cmd start`, `npm.cmd test`를 사용한다. |
| `EADDRINUSE` | 같은 포트를 사용하는 기존 서버를 확인하거나 `PORT`와 `APP_ORIGIN`을 함께 변경한다. |
| 로그인·가입 시 출처 오류 | 브라우저 주소와 `APP_ORIGIN`의 프로토콜·호스트·포트가 같은지 확인한다. |
| 429 응답 | 인증 시도 제한이다. 최대 15분 후 재시도한다. |
| 과목이 다른 계정에서도 표시됨 | 현재 과목 저장소는 같은 브라우저·출처에서 계정 간 공유된다. |
| 과목 저장 실패 | 브라우저 사이트 저장 권한과 저장 공간을 확인한다. |
| 데이터가 예상과 다름 | 저장된 과목·선택 학년이 있는지 확인한다. 학과·기준·초기 과목은 예시 데이터다. |
