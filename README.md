## 실행

Node.js 24.12.0 이상에서 `npm.cmd start`를 실행하고 [http://localhost:3000/](http://localhost:3000/)에 접속합니다. 로그인 또는 회원가입 후 학업 대시보드로 이동합니다. 별도 패키지 설치는 필요하지 않습니다.

대시보드의 과목 현황에서 과목을 추가·수정·삭제할 수 있고, 변경하면 학점·GPA·성적 그래프도 갱신됩니다. **과목과 선택 학년은 사용자별 SQLite DB에 저장**되어 다른 계정과 분리되고, 같은 계정으로 다른 브라우저에서도 조회할 수 있습니다. 처음 사용할 때는 빈 과목 목록과 1학년으로 시작합니다. 수료·졸업·평가 기준은 예시입니다. 기존 브라우저 공용 과목은 소유자를 확인할 수 없어 자동 이전하지 않으며, 기존 저장값도 삭제하지 않습니다.

계정·세션은 `storage/team07.db`, 개인 학사 데이터는 `storage/users/<서버가 발급한 난수>.db`에 저장됩니다. 기존 계정도 학사 데이터 최초 조회 시 전용 DB가 자동 생성됩니다. 서버는 로그인 세션으로만 DB를 선택하며, 다른 계정 지정이나 출처가 다른 저장 요청을 거부합니다. 여러 화면에서 동시에 수정하면 이전 버전의 저장은 거부하므로 새로고침 후 다시 입력하세요. 자세한 API와 보관·백업 주의사항은 [인증 및 데이터 저장 안내](README-auth.md)를 참고하세요. 아래 개발 기록은 당시 상태를 설명하며, 저장 방식은 이 안내가 최신입니다.

자세한 파일 연결, 실행 방법, 검증 결과는 [index.html 실행 안내](dev_log/2026-11-13_index_html_실행방법.md)를 참고하세요.

대시보드의 **졸업까지 남은 학점**에서 전체·전공 잔여 학점을 확인할 수 있습니다. `js/credits/graduation.js`를 연결해 전체 학기의 이수 완료 과목(F 제외)과 수강 중 과목을 합산하며, 과목 추가·수정·삭제 시 자동 갱신됩니다. 수강 중 과목은 이수를 가정한 예상치이고, 졸업 기준은 `data/academic_requirements.json`의 예시 값(전체 130학점·전공 70학점)을 사용합니다. 학기별 과목 조회 필터나 현재 학년 선택은 졸업 잔여 학점에 영향을 주지 않습니다.

주요 기능의 **성적 분석**을 누르면 별도 성적 분석 대시보드(`/grade-analysis.html`)로 이동합니다. 로그인 계정의 전용 DB에 저장된 과목으로 학기별 전체·전공·교양 GPA 그래프를 표시하며, 예시 상대평가 기준의 등급별 예상 인원 그래프와 표를 제공합니다. 수강자 수와 등급별 비율을 바꾸면 예상 인원이 갱신됩니다.
