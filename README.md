## 실행

Node.js 24.12.0 이상에서 `npm.cmd start`를 실행하고 [http://localhost:3000/](http://localhost:3000/)에 접속합니다. 로그인 또는 회원가입 후 학업 대시보드로 이동합니다. 별도 패키지 설치는 필요하지 않습니다.

대시보드의 과목 현황에서 과목을 추가·수정·삭제할 수 있고, 변경하면 학점·GPA·성적 그래프도 갱신됩니다. 과목은 이 브라우저에 저장되며 새로고침 후에도 유지됩니다. 처음 사용할 때는 예시 과목을 표시하고, 모든 과목을 삭제하면 빈 목록을 유지합니다. 학과·학년·학사 기준은 예시이고, 과목의 계정별 저장 및 서버 동기화는 아직 지원하지 않습니다.

자세한 파일 연결, 실행 방법, 검증 결과는 [index.html 실행 안내](dev_log/2026-11-13_index_html_실행방법.md)를 참고하세요.

주요 기능의 **성적 분석**을 누르면 별도 성적 분석 대시보드(`/grade-analysis.html`)로 이동합니다. 같은 브라우저에 저장된 과목으로 학기별 전체·전공·교양 GPA 그래프를 표시하며, 예시 상대평가 기준의 등급별 예상 인원 그래프와 표를 제공합니다. 수강자 수와 등급별 비율을 바꾸면 예상 인원이 갱신됩니다.
