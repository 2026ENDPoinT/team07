## 실행

Node.js 24.12.0 이상의 24.x에서 최초 `npm.cmd ci` 후 `npm.cmd start`를 실행하고 [http://localhost:3000/](http://localhost:3000/)에 접속합니다. 로그인 또는 회원가입 후 학업 대시보드로 이동합니다.

**Render 무료 플랜 + Supabase 배포를 지원합니다.** `DATABASE_URL`이 없으면 기존 사용자별 SQLite를, 있으면 Supabase PostgreSQL의 사용자별 데이터를 사용합니다. 과목·학년·동시 수정 방지와 화면 기능은 동일합니다. `render.yaml`과 [배포 안내](SUPABASE-SETUP.md)를 참고하세요. 유료 Render 디스크는 필요하지 않습니다.

대시보드의 과목 현황에서 과목을 추가·수정·삭제할 수 있고, 변경하면 학점·GPA·성적 그래프도 갱신됩니다. **과목과 선택 학년은 사용자별로 저장**되어 다른 계정과 분리되고, 같은 계정으로 다른 브라우저에서도 조회할 수 있습니다. 처음 사용할 때는 빈 과목 목록과 1학년으로 시작합니다. 수료·졸업·평가 기준은 예시입니다. 기존 브라우저 공용 과목은 소유자를 확인할 수 없어 자동 이전하지 않으며, 기존 저장값도 삭제하지 않습니다.

로컬 SQLite 모드에서 계정·세션은 `storage/team07.db`, 개인 학사 데이터는 `storage/users/<서버가 발급한 난수>.db`에 저장됩니다. 기존 계정도 학사 데이터 최초 조회 시 전용 DB가 자동 생성됩니다. 서버는 로그인 세션으로만 저장 대상을 선택하며, 다른 계정 지정이나 출처가 다른 저장 요청을 거부합니다. 여러 화면에서 동시에 수정하면 이전 버전의 저장은 거부하므로 새로고침 후 다시 입력하세요. 자세한 API와 보관·백업 주의사항은 [인증 및 데이터 저장 안내](README-auth.md)를 참고하세요. 아래 개발 기록은 당시 상태를 설명하며, 저장 방식은 이 안내가 최신입니다.

자세한 파일 연결, 실행 방법, 검증 결과는 [index.html 실행 안내](dev_log/2026-11-13_index_html_실행방법.md)를 참고하세요.

대시보드의 **졸업까지 남은 학점**에서 전체·전공 잔여 학점을 확인할 수 있습니다. `js/credits/graduation.js`를 연결해 전체 학기의 이수 완료 과목(F 제외)과 수강 중 과목을 합산하며, 과목 추가·수정·삭제 시 자동 갱신됩니다. 수강 중 과목은 이수를 가정한 예상치이고, 졸업 기준은 `data/academic_requirements.json`의 예시 값(전체 130학점·전공 70학점)을 사용합니다. 학기별 과목 조회 필터나 현재 학년 선택은 졸업 잔여 학점에 영향을 주지 않습니다.

주요 기능의 **성적 분석**을 누르면 별도 성적 분석 대시보드(`/grade-analysis.html`)로 이동합니다. 로그인 계정의 전용 DB에 저장된 과목으로 학기별 전체·전공·교양 GPA 그래프를 표시하며, 예시 상대평가 기준의 등급별 예상 인원 그래프와 표를 제공합니다. 수강자 수와 등급별 비율을 바꾸면 예상 인원이 갱신됩니다.

주요 기능의 **일정 관리**를 누르면 별도 달력 대시보드(`/calendar.html`)로 이동합니다. 월 이동·오늘 이동·날짜 선택으로 일정을 조회하고, 제목·시작 날짜/시간·종료 날짜/시간·메모를 입력해 일정을 추가·수정·삭제할 수 있습니다. 시작일과 종료일이 같고 두 시간을 비우면 종일 일정입니다. 여러 날짜에 시간이 없으면 종료일까지 종일 일정으로, 시간이 있으면 시작~종료 시간으로 표시합니다. 여러 날에 걸친 일정은 해당 날짜와 월에 모두 표시하며, 종료 시간이 자정(00:00)이면 종료일에는 표시하지 않습니다. 기존 단일 날짜 일정도 계속 조회·수정할 수 있습니다. SQLite에서는 기존 사용자별 전용 DB에, Supabase에서는 비공개 `app_private.calendar_state`에 로그인 계정별로 저장합니다. 기존 DB는 자동 갱신되며, 학사 데이터와 일정의 저장 버전은 독립적입니다. 다른 화면에서 먼저 변경한 일정은 덮어쓰지 않고 최신 일정 불러오기를 안내합니다.

달력 상단의 **연도·월 드롭다운**으로 원하는 달을 바로 선택할 수 있습니다. 지원 범위는 기존 날짜 저장 형식과 동일한 **1~9999년**이며, 범위 밖의 값은 날짜 계산 전에 거부합니다. 양 끝 연도에서는 범위를 벗어나는 이전·다음 달 이동을 막습니다. 연·월 선택은 화면 조회만 바꾸고 저장 API를 호출하지 않아 기존 일정과 저장 버전을 유지합니다.

일정 추가·수정에서 **디데이로 설정**을 선택하면 시작 날짜를 기준으로 달력과 일정 상세에 `D-N`, `D-Day`, `D+N`을 표시합니다. 브라우저의 현지 날짜로 디데이 당일에 로그인하거나 메인화면에 접속하면, 오늘이 디데이인 모든 일정을 상단 알림에 표시합니다. 여러 날 일정도 시작일에만 알림이 뜹니다. **닫기**를 누르면 해당 계정의 당일 알림을 닫은 기록을 브라우저에 저장하므로, 같은 브라우저에서 새로고침·메인화면 재접속·재로그인을 해도 그날은 다시 표시하지 않습니다. 다른 계정이나 다음 날짜의 알림에는 영향을 주지 않습니다. 브라우저 저장 데이터를 삭제하거나 다른 브라우저를 사용하면 다시 표시될 수 있습니다. 디데이 설정은 기존 일정과 함께 계정별로 저장되며, 기존 일정은 디데이를 설정하지 않은 상태로 유지됩니다.

과목의 학기는 `YYYY-1`, `YYYY-2`, `YYYY-여름`, `YYYY-겨울`을 지원하고, 학점은 1~12 사이 정수로 입력합니다. 학기 필터와 성적 그래프는 1학기 → 여름 → 2학기 → 겨울 순서로 계산합니다. 이전 화면의 `/api/courses`도 동일한 계정별 저장소에 연결됩니다.
